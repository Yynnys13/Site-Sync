# HTML

Site Sync では、**ページのHTMLも編集**し、その結果をプレビューで確認できます。

## HTMLの場所
訪問した各ページは、「フォルダー + `index.html`」の形式で `site/` 以下に保存されます。

| URL | ローカルファイル |
|---|---|
| `/` | `site/index.html` |
| `/products` | `site/products/index.html` |
| `/products/123` | `site/products/123/index.html` |
| `/about.html` | `site/about.html` |
| `/page.php` | `site/page.php.html` |

いちばん簡単な方法: サイドバーの **📄 ページのHTMLを編集**(または *Site Sync: Open Page HTML*)で、現在表示中のページのファイルが開きます。

## ページを編集する
1. HTMLファイルを開いて編集し、保存します(`Ctrl + S`)。
2. Site Sync が変更を検出し、プレビューの**ページを再読み込み**します。
3. ファイルが元のものと異なる間は、**リモートのページの代わりにこのファイルが配信**されます。

## 未変更のページは「ライブ」のまま
編集していないページは、引き続きリモートサイトから配信されます(動的なコンテンツ、ログイン中のセッション)。ローカルのコピーは、訪問のたびに**更新**されるだけです。ファイルを元の内容に戻すと、ページは再びライブになります。

> **注意** — ローカルで変更したページは**固定**されます。動的なコンテンツ(データ、CSRFトークン、表示中のログイン状態)は更新されなくなります。モックアップのテストには便利ですが、個人向けに生成されるページでは注意してください。

## Site Sync が書き換えるもの(プレビューのみ)
ローカルファイルは**あなたのHTMLのまま**です。プレビューでのみ、その場で次の処理が行われます: 自ドメインの絶対URL → 相対URL、CDN → プロキシ経由、`integrity` と CSP の `<meta>` を削除、ライブリロード用クライアントを追加。これらがファイルに書き込まれることはありません。

## 制限事項
- **クエリ文字列は無視**されます: `/search?q=a` と `/search?q=b` は同じファイルを共有します。
- HTML は**全体が再読み込み**されます(JS の状態を壊さないため、DOM の部分更新は行いません)。
- HTML は訪問のたびにサーバーと比較され、*更新* では比較されません(匿名リクエストではログイン中のページを再現できないため)。そのため、変更済みのページはリモートと比較されず、HTML には「リモート版をダウンロード」がありません。やり直すにはローカルファイルを削除してください。
- 保存されるのは**自ドメイン**のドキュメントのみです。設定: `.vscode/site-sync.json` の `downloadHtml`。
- `fetch`/XHR で読み込まれるHTMLの断片は保存されません(ページと iframe のみ)。
- コピーにはセッションの個人データが含まれる場合があります。確認せずに `site/` をコミットしないでください。
