# CSS

## CSSの場所
リモートのパスは、そのまま `site/` 以下に再現されます。

```
https://example.com/assets/css/main.css   →   site/assets/css/main.css
```

CSS は Site Sync の **リソース › CSS** ビューにも表示されます(クリックで開く)。

## CSSを編集する
1. CSSファイルを開きます。
2. コードを編集します。
3. 保存します(`Ctrl + S`)。
4. Site Sync が変更を検出します(150 ms の短い*デバウンス*の後)。
5. プレビューに新しいCSSが反映されます。

## ライブリロード
CSS は**ホット更新**されます。対応する `<link rel="stylesheet">` が再読み込みしたコピーに置き換えられ、その後に古いものが削除されます。ページは再読み込みされず、JS の状態やスクロール位置も保持されます。

> **制限** — CSS が `<link>` タグで参照されていない場合(たとえば別のCSS内の `@import` やインラインの `<style>`)は、ページ全体が再読み込みされます。JavaScript によって動的に挿入されたCSSも同様です。

自ドメインを指す絶対 `url(...)` や `@import` はプロキシ内に戻され、CDN を指すものは `/__ss_ext/…` 経由となり、同様に傍受されます。
