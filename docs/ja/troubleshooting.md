# トラブルシューティング

技術的な詳細は **出力 › Site Sync** にあります。

| 問題 | 考えられる原因 / 対処 |
|---|---|
| 「先にフォルダーを開いてください」 | Site Sync はワークスペースにファイルを保存します: *ファイル > フォルダーを開く* |
| 「接続が拒否されました」 | サイトに到達できない、またはURL/ポートが間違っています |
| 「HTTPS 証明書が無効です」 | 自己署名証明書です。信頼できるサイトなら `siteSync.allowInsecureTls` を有効にしてください |
| CSS の変更が反映されない | ファイルが正しいパスで `site/` にあるか確認してください。Service Worker がキャッシュを返している場合があります。*リソース* ビューに表示されていますか? |
| JS でページ全体が再読み込みされる | 仕様です: HMR はありません([JavaScript](javascript.md) を参照) |
| 白紙のページ / サイトが壊れる | サイトが WebSocket、OAuth、特定のオリジンに依存している可能性があります。ログを確認してください |
| 開始のたびにログアウトされる | ポートが変わっています: `siteSync.proxyPort` を設定してください |
| CDN が置き換わらない | JS 内で動的に組み立てられたURLです(JavaScript の制限事項を参照) |
| リソースが取得されない(HTTP 404) | メッセージはログにあります。失敗したリソースは保存されません |
| 書き込みエラー | ファイルとフォルダーが同じ名前です(`/a` と `/a/b.css`) |
| インターフェースの言語が違う | サイドバーの *言語* セレクター、または `siteSync.language` を使用してください |
