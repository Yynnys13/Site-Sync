# Site Sync の使い方

Site Sync を使うと、**リモートWebサイトのHTML・CSS・JS・その他のリソースをローカルで編集**し、その結果をプレビューでリアルタイムに確認できます。

## 1. URLを入力する
**Site Sync** サイドバーに、たとえば `https://example.com` と入力します。

## 2. 「開始」をクリックする
サイトがプレビュー(VS Code 内蔵ブラウザー)で開きます。サイトは**ローカルプロキシ**(`http://127.0.0.1:4173`)経由で読み込まれます。

## 3. リソースの取得を待つ
Site Sync は、ページが実際に読み込んだリソース(CSS、JS、画像、フォントなど)を `site/` フォルダーに取得します。

## 4. ファイルを編集する
Site Sync の **リソース** エクスプローラーから、たとえば `site/assets/css/main.css` を開きます。

## 5. 保存する
`Ctrl + S`。

## 6. 結果を確認する
CSS は**ページを再読み込みせず**に反映されます。JS や HTML を変更した場合はページが再読み込みされます。

## 7. ページを移動する
別のページに移動すると、不足しているリソースが自動的に取得されます。既に存在するファイルは再ダウンロードも上書きもされません。

> **メモ** — このガイドは自動では一度だけ表示されます。設定: `siteSync.showWelcome`。コマンド: *Site Sync: Open Getting Started*。

さらに詳しく: [Site Sync の使い方](usage.md) · [CSS](css.md) · [JavaScript](javascript.md)。

## サイトのインポート
まず**ワークスペースのフォルダー**を開き(ファイル > フォルダーを開く)、サイトを開始します。`site/` フォルダーと `.vscode/site-sync.json` がそこに作成されます。
